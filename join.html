带着你的火来。

地火不是一个只供参观的地方。我们更希望你是来做点什么的。 不用先证明自己够格——带上一个问题、一个念头，或者一门想学的手艺就够了。

01 / WAYS IN

几种进来的方式。

没有统一的会员流程，也没有必须遵守的“创客礼仪”。 先找到最适合你当下状态的那一种。

01

成为会员 / 常来动手

使用空间与设备，参与正在进行的项目，和不同背景的人一起做东西。 从修一个小物件开始，也算。

02

发起项目 / 招募伙伴

有想法，但缺人、缺设备、缺经验？把需求发出来。 我们会帮你找到可能感兴趣的人，也帮你把目标切小。

03

共建空间 / 捐设备与材料

闲置的工具、材料、书、零件，可能在这里重新派上用场。 空间本身也是一个持续迭代的项目。

04

合作与教学 / 机构与学校

课程、工作坊、企业共创。把动手这件事带到更多地方， 也把外面的真实问题带进来。

02 / WHO WE NEED

我们需要的，
不只是“技术大牛”。

一个项目能做成，靠的往往不是最强的单项能力， 而是有人愿意补位、愿意试、愿意把过程讲清楚。

结构 / 机械 电子 / 嵌入式 软件 / AI 设计 / 视觉 教育 / 课程 无线电 / 射频 木工 / 金工 内容 / 摄影 项目管理 什么都想试试

以上都不是门槛。不会可以学，没做过可以从最小的任务开始。 我们更在意你是否愿意持续出现，而不是简历上写了什么。

03 / FIRST STEP

从一句话开始。

不需要准备提案。下面这条路径只是为了让你知道大概会发生什么， 实际可以随时跳过或打乱。

01

打个招呼

在 GitHub 开一条 Issue，简单说说你是谁、想做什么。 或者直接来现场，看到有人在焊东西就打个招呼。

02

聊聊想法

想解决什么问题？卡在哪？已经试过什么？ 不用讲得漂亮，越具体越好。

03

定一个小目标

一次能做完、能看到结果的那种。比如“让电机转起来”、 “打印一个能装上的支架”、“带五个孩子做完一盏灯”。

04

开干

用工具，找人帮忙，记录过程。做完之后，把经验和坑留给下一个人。
