HOW TO JOIN

You don’t need to be ready.
Claim a small piece first.

Co-creation is not as formal as “joining a team.” You can do just one small step: draw a structural sketch, solder a board, write a script, run a trial class with kids.

01

Pick a direction, or propose a new one

Look through the projects above and find one that interests you. None? Your problem might be the next project.

02

Claim it or ask a question on GitHub

Every project has an “I’m interested” link that opens a new issue with the project name. Tell us what you can do and what you would like to know.

03

Meet once, then start

Talk through the goal, the boundaries and the first step. A small goal you can finish beats a grand plan.

04

Finish, document, open-source

Keep the drawings, code and failure logs wherever possible. The next person should not have to start from zero.

Project status changes: Preparing, Recruiting, In progress, Completed. For the latest, check the GitHub issue and talk to us in person; this page is updated regularly.
