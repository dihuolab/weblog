HOW TO JOIN

不需要准备好，
先来认领一小块。

共创不是“加入一个团队”那么正式。你可以只做其中一小步： 画一张结构图、焊一块板、写一段脚本、带孩子试一次课。

01

选一个方向，或提出新方向

看看上面的项目，找一个你感兴趣的。没有也没关系，你的问题可能就是下一个项目。

02

在 GitHub 上认领或提问

每个项目都有“我想参与”入口，会带着项目名打开一条新 Issue。 写清楚你能做什么、想了解什么就够了。

03

约一次碰头，然后开干

聊清楚目标、边界和第一步。定一个很小、但能做完的目标，比宏大的计划更有用。

04

做完，记录，开源

过程里的图纸、代码、失败记录，尽可能留下来。 这样下一个人就不用从零开始。

项目状态会变化：筹备中、招募中、进行中、已完成。 具体进展以 GitHub Issue 和线下沟通为准，这个页面会定期同步。

START SOMETHING

你的项目，
也可以从这里开始。

不需要完整的商业计划，也不需要先组好队。 把你正在卡住的那个问题写下来，我们看看能不能一起往前推一步。
