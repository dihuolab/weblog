HOW IT WORKS

一份手册，
三段现场。

主持人看流程和预案，学员看任务和检查清单。同一份页面， 在开始前、现场和结束后都能直接用。

01

开始前 / Prepare

目标、产出、物料、场地、设备与安全边界。先把不确定的地方写清楚。

02

现场 / Run

时间线、主持人动作、学员任务、检查点和常见故障处理。

03

结束后 / Review

保留有效做法，记录踩过的坑，把下一次要改的地方写回手册。
